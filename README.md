# Directorio de Contactos

Directorio interactivo de contactos universitarios y profesionales.

## Tech Stack
- Angular 22 + Tailwind CSS v4
- Supabase (PostgreSQL)
- Leaflet (Mapas)
- GitHub Pages

## Desarrollo
```bash
cd directorio
npm install
ng serve
```

## Despliegue
```bash
ng build --configuration production
# Output en dist/directorio/browser/
```

## Admin
- Ruta: `/admin-secreto`
- Credenciales en Supabase Auth
